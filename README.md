# CoLearnX

CoLearnX 是一个培训课程网站。访客可以浏览已发布的课程；登录后按身份进入各自的工作区。

## 现在能做什么

- 浏览课程和课程详情
- 会员：选课与学习、我的课程、积分支付、徽章和账户
- 讲师：准备班期、出勤和学员
- 课程创建者：创建课程、确认排期、上传资料
- 管理员：审批、用户、积分账本、争议和审计记录

会员、讲师和课程创建者使用同一套账号，可以在自己的身份之间切换。管理员使用单独的登录入口。

## 本地运行

用 Visual Studio 打开解决方案并启动 `CoLearnX.Server`。开发时页面由前端项目提供，接口由 ASP.NET Core 提供。
