# CoLearnX 设计规格

本目录只保留**现行**设计材料。旧版报告、幻灯片、个人稿、生成脚本不在仓库内。

| 路径 | 用途 |
|------|------|
| `DESIGN-TOKENS.md` | 四角色同一套配色与壳 |
| `FRAMEWORK.md` | 代码分层对照 |
| `source/plan_content.md` | 项目计划可读摘要（需求/用例） |
| `CoLearnX_Project_Plan_Full.docx` | 正式项目计划（FR/NFR、用例、数据模型） |
| `wireframes/drawio/` | 四角色线框 + 业务流程图 |
| `diagrams/` | 架构、用例、ER、序列/活动/状态图 |
| `project-plan/figures/` | 角色交互与系统架构配图 |
| `prototype/` | 可点击 HTML 流程（Member / Admin） |

实现以代码为准；本目录用于对照线框与需求，不要另起一套 UI 或接口。
