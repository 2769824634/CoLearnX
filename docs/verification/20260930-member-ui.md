## 实现与接口

| 功能 | 实现 |
| --- | --- |
| Member 顶栏钱包 | `MemberShell.jsx` 使用 AuthContext 的 `creditBalance` 和 `heldCredits`，主数字为可用积分，附 `On hold`，点击进入 Payment。 |
| Catalog 评分 | `MemberCatalogPage.jsx` 显示一位小数的平均星级、评价数；无评分显示 `New · No ratings yet`。 |
| 详情状态和人数 | `CourseService.GetByIdAsync` 保留 Published、InProgress、Completed、Cancelled 班次；按 Intake 汇总 Reserved 和 Active 人数，隐藏 Draft、PendingApproval、Rejected。 |
| 预约按钮 | `sessionAvailability.js` 统一判断取消、进行中、已完成、已确认、未开放、报名截止、线下截止、满员及无场次；默认选第一个可预约场次，并在确认时再次校验时间。线上容量 0 仍不限人数。 |

`GET /api/courses/{id}` 的 Session DTO 增加 `intakeStatus`、`intakeEnrollmentCount`、`confirmedToRunAt`、`cancelledAt`。接口路径及既有字段保留，无数据库结构变更。人数仅返回汇总，不返回学员身份；新展示的历史及取消场次不返回会议链接。

入口：`CoLearnX.Server/Contracts/Dtos/ApiDtos.cs`、`CoLearnX.Server/Services/AppServices.cs`、`colearnx.client/src/pages/member/MemberDataContext.jsx`、`MemberCourseDetailPage.jsx`、`colearnx.client/src/styles/member.css`。
