## 1. 账户

注册 → 验证邮箱 → 登录 → 会员引导 → 首页

忘记密码 → 重置密码 → 重新登录

编辑资料 → 更换头像

## 2. 角色

会员提交培训师或创作者申请 → 管理员通过 → 切换到新角色

管理员拒绝 → 申请人不能进入该角色

## 3. 创作者建课

选学科、级别、学时、总价 → 上传材料 → 选兴趣 → 提交 → 管理员通过 → 已发布

管理员驳回 → 创作者修改 → 再次提交 → 通过

价格和学时要各测一次：

- 九格各自的最低总价，学时落在该级别区间内 → 能保存
- 总价低于下限 → 拒绝
- 总价高于上限且不超过两倍，不填理由 → 拒绝
- 同上并填写理由 → 超额课建立 → 管理员能看到理由 → 通过
- 总价超过上限两倍 → 拒绝
- 学时超出该级别区间 → 拒绝
- 学时在区间内，但总价低于「时薪下限 × 学时」→ 拒绝

## 4. 员工平台课

员工登录 → 按同一价格围栏建课 → 提交 → 管理员通过 → 已发布

这条课的内容分成记在平台账户，不记给某个创作者。

## 5. 培训师

创作者发出邀请 → 培训师接受 → 才能被选进开班

培训师拒绝 → 不能被选为该课培训师

## 6. 开班

已发布课程 → 创作者或员工建班（最少 2 人、报名起止、课次、线下地址或会议链接）→ 发布

管理员修改开班日期 → 课次时间跟着有效

## 7. 报名到证书

会员浏览目录 → 打开课程 → 报名（学分冻结，状态为已预留）→ 报名截止且人数达到最低人数 → 确认开班（学分扣下，状态变为在读）→ 分成入账 → 培训师点名出勤 → 测评通过 → 结课 → 会员提交证书 → 培训师通过 → 管理员按课程级别签发 PDF → 该会员下载

分成要核对四笔去向：内容给创作者，授课给培训师，平台留 50%。若授课人是在职员工，授课分成留在平台，不发给该员工。

证书级别：入门用第 1 阶段模板，中级用第 2 阶段，高级用第 3 阶段。结业模板不选用。

## 8. 退课、取消和争议

报名截止时人数不足 → 冻结学分退回 → 班级取消

开课前足够早退出 → 退还 70% → 分成按留下的学费回冲

已确认的整班取消 → 全额退还 → 分成回到 0

会员发起争议 → 管理员全额退款、部分退款或驳回 → 分成与留下的学费一致

学分不够 → 不能报名 → 去钱包充值后再报

## 9. 证书不通过

未结课、出勤不足 80%，或测评未全部通过 → 不能提交申请

培训师拒绝，或管理员拒绝 → 不签发

另一名会员打开别人的证书 → 看不到

未登录访问证书文件 → 拒绝

## 10. 延期

人数不足取消且该报名可延期 → 学员接受下一班 → 新报名建立，旧报名不再重复延期

## 11. 材料

建课时附带的材料 → 管理员审核通过或驳回

培训师或员工在课次上上传材料 → 学员能在该课次看到

公开目录只浏览、不报名：首页 → 课程列表 → 课程详情
