## 本轮采用的规则

- 所有相关只读日期使用明确的 UTC 展示。`datetime-local` 输入使用浏览器本地时区，转换后按 UTC 保存；无时区后缀的服务端 UTC 数据也按 UTC 解析。
- 混合班保留现有共享名额规则，统一 Member 和 Trainer 的说明。
- Admin 课程审核增加只读兴趣、关联资料版本数量、各状态数量、业务版本号与已有受保护下载入口。
- Reserved 仅显示预约进度和只读预约名单，仍不能访问正式学习资料、出勤、评分和结业操作。
- 通知路径由服务端事件、可信 Intake 与本人 Enrollment 生成，前端继续使用路径白名单。
