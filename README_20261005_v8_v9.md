# CoLearnX 20261005_v8 / 20261005_v9

**作者：Gu Yincheng**

**日期：2026-10-05**

本文概述 CoLearnX v8 与 v9 的主要功能。v8 着重完善已有课程资料、课程班期流程和多角色页面；v9 在此基础上为具体课节增加资料上传，并改善账号操作体验。

## v8：课程班期与现有课程资料完善

- **课程资料预览与版本信息**：修复 PDF 等既有课程资料的格式识别、文件名扩展名和预览资源释放；Admin 审核页面显示资料状态、文件信息和业务版本。
- **上传和错误提示**：校验标题、文件类型及 20 MiB 文件大小限制；将上传失败原因关联到对应控件，并覆盖 PDF、PPTX、DOCX、PNG、JPG/JPEG 等格式。
- **班期与报名信息**：完善 Trainer 创建和管理班期时的日期、时间、名额和人数规则，并让 Trainer 与 Member 看到一致的混合班名额说明。
- **预约与成班情况**：Trainer 可查看预约人数、最低开班人数和还差人数；预约名单只读，并检查操作人的班期归属。
- **通知与班期导航**：通知带上可信的 Intake 和本人 Enrollment 关联，点击后进入相应班期或报名记录；旧通知仍可安全回退到列表。
- **多角色页面与时间显示**：改善 Trainer、Creator、Member 和 Admin 的班期审核、资料展示、表单错误、预约结果及 UTC 时间显示。

v8 的课程资料改进针对系统已有的课程资料、审批和预览流程。每个课节独立上传讲义是 v9 新增的能力。

## v9：课节资料与账号体验

- **按课节上传资料**：Trainer 在班期详情页为具体 Session 上传带标题的 PDF、PPTX、DOCX、PNG 或 JPG/JPEG 文件，单文件上限 20 MiB；同一页面可查看并下载该课节的资料。
- **Member 学习中心**：Active 或 Completed 的本人报名可按课节查看和下载资料；Reserved 报名不开放学习资料。
- **保护已有资料**：已有课节资料时，不允许删除课节或提交会修改该课节结构的变更；Trainer 提交和 Creator 确认阶段都会检查并保留文件。
- **邮件密码重置**：从邮件链接打开重置页后，只需输入新密码和确认密码，账号由重置 token 确定；旧登录会话在密码重置后失效。
- **显示或隐藏密码**：登录、注册、Admin 登录及密码重置表单均提供小眼睛按钮。
- **修复个人资料编辑焦点**：编辑值变化时不再重置弹窗焦点；连续输入会留在当前字段。
